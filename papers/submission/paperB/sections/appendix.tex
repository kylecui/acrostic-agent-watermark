\section{Artifact and Configuration}
\label{app:config}
All experiments run from fixed-seed scripts against AAWM v0.15.0 (commit
\texttt{6abba24} series) with data files under \texttt{papers/paperB/data/}
and figures generated by the same scripts. Core configuration: 16 bands;
zero-cost Chinese dictionary (136 groups) and English dictionary (133
groups); bias 1.0; registry of 50 users (uids 1000--1049) unless varied;
explicit-salt trace path; uncalibrated defaults are the v0.15 constants
(intercept 0.7, slope 1.35). Domains and seeds are recorded per experiment
in the data JSON files. PostMark experiments use the official repository
at commit \texttt{347f159} with the \texttt{nomic} embedder, ratio 0.12.

\section{PostMark Environment Notes}
The PostMark pipeline required torch 2.6/cu124, transformers 4.46.3
(transformers 5.x is incompatible with the nomic custom modeling code),
and the embedding-table data files from the companion HuggingFace dataset
(verified against the published SHA256SUMS). Reproduction steps are in the
artifact's \texttt{papers/third\_party/NOTES.md}.
