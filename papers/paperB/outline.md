# 论文 B 章节大纲（M1 交付物 · 随写作迭代，论点冻结于 PLAN §4.1）

工作标题：*Correlated Votes, Non-transferable Null Models, and the
Template Attack: Pitfalls of Statistical Watermarks on Text*

目标 venue：arXiv 首发 → ACL/EMNLP workshop 或二线安全会议。

## 1. Introduction（~1 页）
- Hook 1：文本水印部署者按"检出率 90–100%"采购，但三个系统性失效
  模式让该数字在真实语料上坍缩——我们逐一构造、复现、量化。
- 三个 finding 各一句 + 缓解设计一句 + artifact 声明（AAWM v0.15、
  全部实验 fixed seed 公开）。
- 贡献列表（冻结）：
  C1 F1：确定性词谓词 + 出现次数计票 ⇒ z 随重复线性膨胀（构造 +
     修复 + 权衡曲线）
  C2 F2：经验阈值标定的域特定性实测（6 域 × 3 配置矩阵）
  C3 F3：重复模板文伪造存在性且突破弃权协议的误归因（机理 + 缓解分级）

## 2. Background & Problem Setting（~1 页）
- 词汇级统计水印的一般形式化：词谓词 g_K(w)∈{0,1}、分带映射、
  计票向量 n_b/g_b、逐带 z、存在性得分 Σ|z|、经验阈值。
- AAWM 作为实例一句话（双信道不在本文范围，一句话交代）。
- 威胁模型：攻击者知有水印、不知密钥；可编辑文本（插入/删除/
  同义替换/模板构造）；验证者持密钥与可选 meta。
- 判定协议：existence → attribution → abstain（我们的弃权协议作
  为被测对象之一）。

## 3. Finding 1: Correlated Votes（~1.5 页）——E-B1, E-B2
- 3.1 失效构造：同一词重复 N 次，z 实测 ∝√N 无界（fig_eb1）。
- 3.2 根因：g_K 确定性 ⇒ 重复样本完全相关，二项方差公式失真。
- 3.3 缓解：PER_WORD_CAP 封顶；权衡曲线（fig_eb2：cap=3 时域内
  TPR 最高且 FPR=0；cap≥5 时 FPR 抬头）。
- 3.4 讨论：封顶不是无代价（cap=1 时 TPR=0）；一般性结论——
  一切"确定性谓词+计票"方案同病（E-B4 外部复现佐证/理论论证）。

## 4. Finding 2: Non-transferable Null Models（~1.5 页）——E-B3
- 4.1 实验矩阵：6 域 × {未标定, 跨域标定, 域内标定}。
- 4.2 核心结果：跨域标定 FPR 19–53%（比不标定的 0–2.5% 更糟）；
  域内标定 FPR 0–7%。（fig_eb3）
- 4.3 机理：z 的零分布由用词习惯决定，技术散文的"正常波动"≠
  古典文学的"正常波动"。
- 4.4 部署铁律 + 对研究界的呼吁：论文报检出率必须带域/标定限定。

## 5. Finding 3: The Template Attack（~1.5 页）——E-B6, E-B7
- 5.1 构造：重复模板文本（表单/模板/刷量的真实类别）。
- 5.2 双重失效：存在性 FPR 高 + **误归因**（attr-FPR 随注册库规模
  上升，fig_eb6）；为什么 abstain 协议救不回（机理量：得分占比与
  带方向一致率——信号与噪声候选真实对齐）。
- 5.3 缓解分级（fig/tab）：域内标定（唯一清零）> 业务层相似度
  预过滤（E-B7）> 无缓解。
- 5.4 讨论：这是统计水印对一类常见真实文本的结构性边界，不是实现 bug。

## 6. Recommendations（~0.5 页）
- 给部署者：域内标定 / PER_WORD_CAP / 模板预过滤 / 归因结论必须带
  置信与弃权。
- 给研究者：报告口径（域、标定、长度带、盐路径）/ 把重复构造纳入
  标准攻击集。
