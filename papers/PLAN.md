## 3. 证据与诚实约束（最高优先级，违反即返工）

1. **一claim一证据**：论文正文每个可检验断言必须有 `E-xx` 实验编号
   + `experiments/paper_*.py` 脚本 + 结果文件。写作时维护
   `papers/paperB/claims.md`（claim → 实验 → 数据文件 映射表），
   投稿前逐条核对。
2. **固定随机性**：所有实验脚本接受 `--seed` 且默认固定；图表可复现
   命令写进每个脚本的 docstring。
3. **阴性结果必报**：每个实验矩阵无论结果好坏都入库并写进论文
   （失败模式是论文 B 的卖点，不是耻辱）。禁止"跑到达标为止"式采样。
4. **统计口径锁定**：FPR/TPR/检出率一律标注（语料域、标定方式、盐路径、
   文本长度带）。禁止跨配置拼接最优数字。
5. **对比公平**：复现他人 baseline 时忠实于其论文参数；我们的调参
   只在标定语料上进行（模拟部署者真实能力），不用测试集调参。
6. **措辞红线**：检出率数字必须带限定条件（域内标定/文本长度）；
   "零感"只能出现在有 LLM 评判数据支撑的地方，否则用"低扰动（代理指标）"。

## 4. 论文 B 详细方案

### 4.1 论点（冻结）

**词汇级统计文本水印的三个被系统性忽视的失效模式，及缓解设计**：

- **F1 相关票膨胀**：词色是密钥的确定性函数，同一词重复 N 次贡献 N 个
  完全相关样本，z 随 N 线性膨胀 → 无水印模板文可越阈并淹没真实 UID 证据。
  缓解：每词每文档计票封顶（PER_WORD_CAP）。
- **F2 null 模型域特定**：阈值标定语料与待测文本跨域时，FPR 从 ~2% 恶化到
  19–53%（比不标定更糟）→ "标定必须域内"从直觉变成实测铁律。
- **F3 模板文攻击**：重复模板文本可伪造存在性信号，且 abstain 类协议
  不能阻止误归因（实测 28% 误归因到具体用户）→ 统计水印对一类常见
  真实文本（表单/模板/刷量）结构性失效。

**普适性主张**（论文 B 的灵魂）：F1/F2 不只属于 AAWM——F1 属于一切
"词级确定性谓词 + 出现次数计票"的方案（词汇级 KGW 变体、PostMark 类），
F2 属于一切经验阈值方案。论文必须包含外部复现（§4.3 E-B4/E-B5）。

### 4.2 章节大纲（Phase 1 第 1 周产出 outline.md，此处为骨架）

1. Introduction（三个坑各一段 hook + 我们的缓解 +  artifact 声明）
2. Background & Threat Model（词汇级统计水印的一般形式化：词谓词、
   计票、z 检验、经验阈值——用一般记号写，AAWM 作为实例）
3. Finding 1: Correlated Votes（攻击构造 → 失效分析 → 封顶修复 →
   信号代价权衡曲线）
4. Finding 2: Non-transferable Null Models（跨域实验矩阵 → 部署铁律）
5. Finding 3: The Template Attack（构造 → 误报 + 误归因 → 为何
   abstain 协议救不回 → 缓解路径分级）
6. Mitigations & Recommendations（给部署者与给研究者的清单）
7. Related Work（词汇级水印、经验阈值校准、LLM 水印部署研究）
8. Limitations & Ethics（单系统设计者的局限；水印的对抗用途风险声明）

## 7. 约束汇总（执行纪律，违者返工）

1. 只在本分支工作；不动 `src/aawm/`（§2）。
2. 一切断言可溯源（§3.1）；固定种子（§3.2）；阴性结果必报（§3.3）。
3. 实验编号即范围：矩阵外的新实验须先补进 PLAN.md 再动手（防止实验蔓延）。
4. 图表禁止手工编辑；数据禁止手工录入。
5. 每周结束更新本文件的进度表（§12），停滞超一周须在 DECISIONS.md 记录原因与处置。
6. 术语统一：检出=existence，归因=attribution，弃权=abstain；论文用语以此为准（文档历史用语不追溯）。
7. API 密钥纪律（v1.1 新增）：一律读环境变量，禁止入库/入日志/入论文
   复现脚本；费用可溯源（每次调用的 model/token 数落 JSON）；E-A1 预算
   上限 ¥200，逼近 80% 时暂停并报告。
